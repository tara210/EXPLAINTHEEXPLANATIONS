      Where this token looks: the dark token is being read; earlier tokens are shaded by how much attention it pays them (darkest = its strongest target). Later tokens are faded, since the model cannot see them yet.

      Received so far: for every token, the attention it has received from all tokens read up to now, relative to an even spread: blue = more, amber = less. Step forward and watch it build up.

      Occlusion effect: how many bits harder the next 20 tokens get to predict when the word is removed (blue = the word helps, amber = removing it helps). Measured with the question present.
